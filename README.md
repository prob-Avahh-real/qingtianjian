# 青天见 (Qing Tian Jian)

融合中国传统**紫微斗数**与现代**西洋占星**的双模命盘排盘应用，基于 Capacitor 封装 Android / iOS 移动端壳，并原生支持智能戒指、智能手杖与智能手表窄屏交互。

## 核心功能

- **紫微斗数排盘**：内置公历转农历算法、天干地支纪年/日/时推算、命宫与身宫定位、十二宫排布（命宫、兄弟、夫妻、子女、财帛、疾厄、迁移、交友、官禄、田宅、福德、父母）、十四主星落宫与十干四化（化禄、化权、化科、化忌）高亮展示。
- **西洋占星星盘**：集成 `swisseph-wasm` 瑞士星历表计算儒略日、十大行星黄道经纬度、整宫制（Whole Sign）上升点（ASC）/中天（MC）与合、六合、四分、三分、对冲五大相位线绘制（支持 `AstroChart` 矢量盘与 Canvas 离线兜底盘）。
- **城市经纬度检索**：内置 Express 地理编码代理服务（`server.js`），离线状态下自动平滑回退至默认坐标。

## 移动端与智能穿戴操控

| 设备形态 | 交互映射 |
|---------|---------|
| 📱 手机触屏 | 输入生辰与城市，点击「📍 定位」与「🌟 排盘」，切换紫微/占星标签 |
| 💍 智能戒指 (`DeviceOrientationEvent`) | 前后倾斜 (`> 5°`) 上下滚动星盘详情；左右倾斜 (`> 5°`) 依次聚焦十二宫卡片；摇晃 (`> 20°`) 立即排盘 |
| 🦯 智能手杖 (`DeviceMotionEvent`) | 轻点地面 (`spike > 8`) 触发排盘；左右摆动 (`> 3`) 在「紫微斗数」与「西洋占星」模式间切换 |
| ⌚ 智能手表 | `@media (max-width: 280px), (max-height: 300px)` 窄屏紧凑布局自适应 |

> iOS 13+ 设备点击顶部「启用穿戴操控」按钮即可在用户手势中完成运动传感器授权。

## 命令与构建

```bash
# 运行冒烟与穿戴同步测试
npm test

# 同步 Web 产物至 www/ 与 Android / iOS 资源目录
npm run build

# 启动本地含地理编码 API 的开发服务器
npm start
```
